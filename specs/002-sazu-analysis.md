# 002. 자체 만세력·Gemini 사주 해석

- 상태: accepted
- 소유: WINGS 팀
- 갱신일: 2026-08-28

## 목표

WINGS 방문자가 로그인 없이 자신의 출생 정보를 입력해 실제 사주 원국을 계산하고, 읽기 쉬운 한국어 해석을 확인한다. 외부 사주 SaaS의 샌드박스·샘플 프로필 제한은 사용하지 않는다.

## 기술 결정

| 항목 | 결정 |
| --- | --- |
| 계산 엔진 | 서버 함수의 `manseryeok` v2 |
| 계산 기준 | KASI 정본 음력·절기, 출생 도시 경도 기반 진태양시 |
| 해석 | 서버 함수의 Gemini `gemini-2.5-flash` |
| API 경계 | `POST /api/sazu` Vercel Function |
| 비밀값 | 서버 환경변수 `GEMINI_API_KEY` |
| 데이터 보관 | 출생 정보·계산 결과·Gemini 응답 모두 영구 저장하지 않음 |

## 범위

- `/sazu`에서 생년월일, 출생 시각(모름 가능), 성별, 양력/음력, 윤달, 출생 도시를 입력한다.
- 서버는 원국, 오행 비율, 일간, 십신, 공망, 대운을 계산한다.
- Gemini는 계산된 결과만 받아 핵심 성향·오행 균형·대운을 볼 때의 관점을 존댓말 한국어로 해석한다.
- 해석은 단정적 예언, 의료·재정 조언을 포함하지 않으며 참고·오락용임을 명시한다.

## 수용 기준

| ID | 기준 |
| --- | --- |
| AC-01 | `/sazu`는 로그인 없이 접근할 수 있다. |
| AC-02 | 유효하지 않은 날짜·시각은 계산 전에 400으로 거절한다. |
| AC-03 | 실제 생년월일은 샘플 프로필 제한 없이 `manseryeok`으로 계산된다. |
| AC-04 | `GEMINI_API_KEY`는 `api/` 서버 코드에서만 읽고 브라우저 번들·네트워크 요청에 노출하지 않는다. |
| AC-05 | 성공 시 원국, 오행, 대운, 계산 요약, Gemini 해석을 표시한다. |
| AC-06 | 출생 시각을 모르면 정오를 임시 계산값으로 사용하되, 해석 입력에 시각 미상 상태를 포함한다. |
| AC-07 | Gemini 호출 실패 시 API 키·출생 정보·원문 응답을 로그 또는 사용자 메시지에 노출하지 않는다. |
| AC-08 | 출생 정보와 해석 결과는 DB·브라우저 저장소에 보관하지 않는다. |

## 실패 처리

| 조건 | 사용자 메시지 |
| --- | --- |
| `GEMINI_API_KEY` 없음 | 사주 해석 기능을 준비 중이에요. 잠시 후 다시 시도해주세요. |
| 유효하지 않은 입력 | 출생일과 시간을 다시 확인해주세요. |
| 계산 또는 Gemini 호출 실패 | 사주 분석을 완료하지 못했어요. 잠시 후 다시 시도해주세요. |
