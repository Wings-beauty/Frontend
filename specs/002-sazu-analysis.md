# 002. SAZU 사주 분석

- 상태: accepted
- 소유: WINGS 팀
- 갱신일: 2026-08-28

## 문제와 목표

WINGS 방문자가 자신의 출생 정보를 바탕으로 사주 원국과 핵심 흐름을 확인할 수 있는 별도 분석 화면이 필요하다. 프런트엔드는 Vite 정적 앱이므로 SAZU API 키를 브라우저에 포함하지 않고도 기능을 제공해야 한다.

목표는 사용자가 출생 정보를 입력하면 한 번의 요청으로 핵심 사주 분석을 확인하는 것이다. API 키와 SAZU 원본 오류 정보는 사용자 브라우저에 노출하지 않는다.

## 범위

### 포함

- 새 경로 `/sazu`의 출생 정보 입력과 결과 화면
- 생년월일, 출생 시각(모름 가능), 성별, 양력/음력, 윤달, 출생 도시 입력
- Vercel Function을 통한 서버 사이드 전용 `@sazuapp/client` 호출
- SAZU 핵심 5개 모듈: `fourPillars`, `elements`, `sinStrength`, `decadeFortune`, `summary`
- 사주 원국 → 오행 분포 → 신강/신약 → 대운 → 요약 순서의 결과 표시
- 인증·호출 한도·일시 장애를 구분한 사용자용 오류 메시지

### 제외

- 브라우저에서 SAZU API 또는 SDK 직접 호출
- 출생 정보·사주 결과의 DB 저장, 진단 기록 연결, 관리자 조회
- AI 해석 텍스트 생성 및 운세·궁합·상담 기능
- 모든 SAZU 모듈의 최초 화면 표시
- 출생 도시의 자동 추론 및 전체 도시 데이터셋 UI

## 기술 결정

| 항목 | 결정 |
| --- | --- |
| API 경계 | `POST /api/sazu` Vercel Function |
| SDK | 서버 함수에서만 `@sazuapp/client` import |
| 비밀값 | 서버 환경변수 `SAZU_API_KEY` |
| 응답 상세도 | `standard` |
| 기본 출생 도시 | 사용자가 비우면 `서울` |
| 데이터 보관 | 요청·응답 모두 영구 저장하지 않음 |
| 로컬 통합 테스트 | Vite 개발 서버가 아닌 `vercel dev` 사용 |

## 사용자 시나리오

### 시나리오 A — 양력, 출생 시각을 아는 사용자

1. 사용자는 `/sazu`에서 생년월일, 출생 시각, 성별, 양력 여부와 출생 도시를 입력한다.
2. 사용자는 분석을 요청한다.
3. WINGS 서버 함수가 SAZU SDK로 분석한다.
4. 사용자는 사주 원국, 오행, 신강/신약, 대운, 요약을 순서대로 확인한다.

### 시나리오 B — 출생 시각을 모르는 사용자

1. 사용자는 출생 시각을 “모름”으로 선택한다.
2. 앱은 `birthHour: null`로 요청한다.
3. 사용자는 시주가 없을 수 있음을 이해할 수 있는 결과 화면을 본다.

### 시나리오 C — 일시 장애 또는 호출 제한

1. 분석 요청이 인증 오류, 한도 초과 또는 일시 장애로 실패한다.
2. 사용자는 키·내부 코드·원문 오류 대신 재시도 가능한 한국어 안내를 본다.
3. 입력 값은 유지되어 사용자가 다시 작성하지 않아도 된다.

## 수용 기준

| ID | 기준 |
| --- | --- |
| AC-01 | `/sazu`는 로그인 여부와 무관하게 접근할 수 있다. |
| AC-02 | 생년·월·일은 각각 정수이며, 연도 1900~2100·월 1~12·유효한 일자 범위를 벗어나면 API 호출 전에 오류를 보여준다. |
| AC-03 | 출생 시각 “모름”을 선택하면 요청의 `birthHour`는 `null`이다. |
| AC-04 | SDK와 `SAZU_API_KEY`는 `api/` 아래 서버 코드에서만 사용되며, `src/` 브라우저 코드에서 SDK를 import하지 않는다. |
| AC-05 | 배포 산출물 및 브라우저 네트워크 요청에서 `SAZU_API_KEY` 값과 `x-api-key` 헤더가 노출되지 않는다. |
| AC-06 | 서버 함수는 `SazuApiError.isAuthError`, `isRateLimited`, `isTransient`를 각각 분기한다. |
| AC-07 | 호출 한도 초과 시 재시도 가능 시간(`retryAfterSec`)이 있으면 사용자 메시지에 표시한다. |
| AC-08 | 성공 시 원국·오행·신강/신약·대운·요약이 빈 상태와 긴 데이터 모두에서 레이아웃을 깨지지 않고 표시한다. |
| AC-09 | 서버는 필요한 5개 모듈만 `standard` 상세도로 요청한다. |
| AC-10 | 출생 정보 및 원본 SAZU 응답을 콘솔 로그, sessionStorage, localStorage, Supabase에 저장하지 않는다. |
| AC-11 | API 실패 후에도 사용자가 입력한 값은 폼에 남아 재시도할 수 있다. |
| AC-12 | `npm run build`와 `vercel dev` 환경의 `/api/sazu` 성공·오류 응답을 확인한다. |

## 데이터·개인정보·보안

- 출생일·시간·성별·출생 도시는 개인 성향 분석에 쓰이는 민감한 맥락의 정보로 취급한다.
- 분석 요청 전 “입력한 출생 정보는 사주 분석 요청에만 사용되며, WINGS는 이 기능에서 저장하지 않습니다.”라는 고지를 표시한다.
- API 키는 `.env.local` 및 Vercel의 Development·Preview·Production 환경변수에만 설정한다. `VITE_` 또는 `REACT_APP_` 접두사는 사용하지 않는다.
- `SAZU_CLIENT_BLOCK_BROWSER=1`을 서버 환경변수에 설정해 SDK의 브라우저 오사용을 차단한다.
- 오류 로그에는 API 키, 원본 요청 본문, 원본 SAZU 응답을 기록하지 않는다. 운영 진단이 필요할 때는 SAZU `responseId`와 오류 코드만 기록한다.

| API 키 없음·폐기·만료 | `isAuthError` 분기, 503 | 사주 분석 기능을 준비 중이에요. 잠시 후 다시 시도해주세요. |
| 분당·월간 한도 초과 | `isRateLimited` 분기, 429 | 요청이 많아요. 잠시 후 다시 시도해주세요. |
| 인증 서비스·SAZU 일시 장애 | `isTransient` 분기, 503 | 분석 서비스 연결이 일시적으로 불안정해요. 잠시 후 다시 시도해주세요. |
| 입력값 오류 | API 호출 전 400 | 출생일과 시간을 다시 확인해주세요. |
| 기타 오류 | 500 | 사주 분석을 완료하지 못했어요. 잠시 후 다시 시도해주세요. |
