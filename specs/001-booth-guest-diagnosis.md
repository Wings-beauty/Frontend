# 001. 부스 무로그인 퍼스널컬러 진단

- 상태: accepted
- 소유: WINGS 팀
- 갱신일: 2026-08-28

## 문제와 목표

팝업 부스 방문자는 자신의 모바일에서 짧은 시간 동안 진단을 완료해야 한다. 가입·로그인 요구는 이탈과 대기열을 늘린다.

목표는 로그인하지 않은 방문자가 사진 선택부터 진단 결과와 추천 상품 확인까지 한 번의 세션에서 완료할 수 있게 하는 것이다.

## 범위

### 포함

- 모바일 우선의 첫 화면, 안내, 사진 선택, 분석, 보정 설문, 결과, 추천 상품 흐름
- 로그인 없이 진단 결과와 추천 상품을 확인하는 세션 흐름
- Supabase 환경변수가 없는 로컬 디자인 미리보기
- `/preview`에서 주요 화면 경로를 빠르게 확인하는 디자인 갤러리

### 제외

- 비로그인 방문자에게 결과를 다시 보여 주기 위한 계정 연결·개인 기록 기능
- 계정 기반 찜·진단 기록·마이페이지 기능
- 관리자·문의 기능의 부스용 데이터 모의화
- AI 분석 모델의 정확도 개선

## 사용자 시나리오

### 시나리오 A — 부스 방문자의 빠른 진단

1. 방문자는 자신의 모바일에서 WINGS 첫 화면을 연다.
2. 방문자는 로그인 없이 이벤트를 시작하고 얼굴 사진을 선택한다.
3. 분석과 필요 시 보정 설문을 완료한다.
4. 방문자는 같은 브라우저 세션에서 퍼스널컬러 결과와 추천 상품을 확인한다.

### 시나리오 B — 행사 운영자의 디자인 확인

1. 운영자는 로컬 서버의 `/preview`를 연다.
2. 운영자는 화면 갤러리에서 부스·사용자·관리자 경로를 선택한다.
3. 진단 결과가 필요한 부스 화면은 샘플 세션 데이터로 즉시 확인한다.

## 수용 기준

| ID | 기준 |
| --- | --- |
| AC-01 | 비로그인 사용자가 `/onboarding`에서 `/photo`로 진행할 수 있다. |
| AC-02 | 비로그인 사용자가 사진 분석 완료 후 `/result`에서 최종 시즌 결과를 볼 수 있다. |
| AC-03 | 비로그인 사용자가 `/recommendation`으로 이동할 수 있으며, 로그인 화면으로 강제 전환되지 않는다. |
| AC-04 | 360px 너비 모바일 화면에서 부스 시작과 사진 선택의 주요 CTA가 가로 스크롤 없이 조작 가능하다. |
| AC-05 | Supabase URL·키가 없는 로컬 환경에서도 앱이 초기화되고 UI를 렌더링한다. 실제 계정·영구 저장 요청은 실행하지 않는다. |
| AC-06 | `/preview`는 부스, 내 활동, 문의·관리자 그룹의 모든 등록 라우트 링크를 제공한다. |
| AC-07 | `/preview`를 열면 결과·추천 화면을 위한 샘플 진단 세션 데이터가 설정된다. |
| AC-08 | 사진 원본은 비로그인 로컬 미리보기 모드에서 영구 저장하지 않는다. |
| AC-09 | 실제 부스 모드의 진단 요청·결과는 `user_id = null`, `requester_type = "guest"`로 DB에 기록하되 사진 원본은 저장하지 않는다. |

## 데이터·개인정보·실패 처리

- 실제 행사 모드에서 사진 전송 전, 사진이 진단 목적으로만 사용된다는 고지를 보여야 한다.
- 비로그인 흐름의 결과는 현재 브라우저 세션 범위로 제한한다. 새 세션에서 다시 보기는 보장하지 않는다.
- AI 분석 키 또는 서비스가 준비되지 않으면, 사진 분석을 완료한 것처럼 보이는 결과를 만들어서는 안 된다. 사용자가 재시도할 수 있는 오류 상태를 보여야 한다.
- Supabase가 설정되지 않은 로컬 미리보기에서는 계정·저장 기능이 실패하지 않도록 네트워크 요청을 만들지 않는다.
